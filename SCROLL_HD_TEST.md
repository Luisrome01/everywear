# Everywear — Scroll Hero HD test

The experimental `video-scroll-test` branch displays a 60-frame scroll-controlled hero, with no autoplaying video.

## Source and output

- `public/scroll-frames/frame_001.webp` through `frame_060.webp`: original 1280 × 720 frames, preserved.
- `public/scroll-frames-hd/`: generated by `npm run prebuild` (also triggered automatically by `npm run build`). Each frame is 1920 × 1080.
- The default home uses the HD frames. Add `?scrollQuality=720` before `#/...` to compare with the originals on the preview domain.
- Scroll advances/rewinds the frames; it does not play a video.

The source video was 720p, so the HD set is **enhanced and upscaled**, rather than true source 1080p. Replacing the original frames with genuine HD video frames is the next quality step if needed.

## Run

```bash
npm install
npm run build
npm run dev
```

Preview site: https://everywear-scroll-preview.onrender.com/

This is a test branch; no changes to `main` or the main production site.
